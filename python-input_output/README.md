# Python - Input/Output

Reading and writing files with `with`, JSON serialization and deserialization, and turning class instances into dictionaries.

| File | Description |
|------|-------------|
| `0-read_file.py` | Prints a UTF-8 text file to stdout |
| `1-write_file.py` | Writes a string to a file and returns the number of characters written |
| `2-append_write.py` | Appends a string to a file and returns the number of characters added |
| `3-to_json_string.py` | Returns the JSON string of an object |
| `4-from_json_string.py` | Returns the object represented by a JSON string |
| `5-save_to_json_file.py` | Writes an object to a file as JSON |
| `6-load_from_json_file.py` | Creates an object from a JSON file |
| `7-add_item.py` | Adds command-line arguments to a list stored in `add_item.json` |
| `8-class_to_json.py` | Returns the attribute dictionary of an instance |
| `9-student.py` | `Student` with `to_json()` |
| `10-student.py` | `Student.to_json(attrs)` filters attributes by name |
| `11-student.py` | Adds `reload_from_json()` to rebuild a student from a dictionary |
| `12-pascal_triangle.py` | Returns Pascal's triangle of `n` rows |
| `100-append_after.py` | Inserts a line after each line containing a search string |
| `101-stats.py` | Reads access logs from stdin and prints file size and status code counts every 10 lines and on CTRL+C |
