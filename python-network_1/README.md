# Python - Network #1

Fetching web resources from Python with `urllib` and `requests`: GET and POST, headers, error codes, JSON APIs and Basic Authentication.

| File | Description |
|------|-------------|
| `0-hbtn_status.py` | Fetches the status URL with `urllib` |
| `1-hbtn_header.py` | Prints the `X-Request-Id` header with `urllib` |
| `2-post_email.py` | POSTs an email with `urllib` |
| `3-error_code.py` | Prints the body, or `Error code:` on `HTTPError` |
| `4-hbtn_status.py` | Fetches the status URL with `requests` |
| `5-hbtn_header.py` | Prints the `X-Request-Id` header with `requests` |
| `6-post_email.py` | POSTs an email with `requests` |
| `7-error_code.py` | Prints the body, or `Error code:` for status >= 400 |
| `8-json_api.py` | Searches users and prints `[id] name`, `No result` or `Not a valid JSON` |
| `10-my_github.py` | Prints a GitHub user id using Basic Auth with a token |
| `100-github_commits.py` | Lists the 10 latest commits of a repository as `sha: author` |
