# Python - More Data Structures: Set, Dictionary

Sets and dictionaries in Python 3: common methods, iteration, and functional tools (`lambda`, `map`, `filter`, `reduce`).

| File | Description |
|------|-------------|
| `0-square_matrix_simple.py` | `square_matrix_simple(matrix)`: squares every value of a matrix |
| `1-search_replace.py` | `search_replace(my_list, search, replace)`: replaces every occurrence in a new list |
| `2-uniq_add.py` | `uniq_add(my_list)`: adds every unique integer once |
| `3-common_elements.py` | `common_elements(set_1, set_2)`: returns the common elements |
| `4-only_diff_elements.py` | `only_diff_elements(set_1, set_2)`: returns the elements present in only one set |
| `5-number_keys.py` | `number_keys(a_dictionary)`: returns the number of keys |
| `6-print_sorted_dictionary.py` | `print_sorted_dictionary(a_dictionary)`: prints a dictionary by sorted keys |
| `7-update_dictionary.py` | `update_dictionary(a_dictionary, key, value)`: replaces or adds a key |
| `8-simple_delete.py` | `simple_delete(a_dictionary, key)`: deletes a key |
| `9-multiply_by_2.py` | `multiply_by_2(a_dictionary)`: returns a new dictionary with every value doubled |
| `10-best_score.py` | `best_score(a_dictionary)`: returns the key with the biggest value |
| `11-multiply_list_map.py` | `multiply_list_map(my_list, number)`: multiplies every value using `map` |
| `12-roman_to_int.py` | `roman_to_int(roman_string)`: converts a Roman numeral to an integer |
