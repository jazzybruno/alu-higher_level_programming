The ``101-lazy_matrix_mul`` module
==================================

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Square and rectangular products:

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

Invalid inputs raise an error (its type and message depend on the NumPy
version, so only the failure is checked):

M_a is a string:

    >>> try:
    ...     lazy_matrix_mul("string", [[1, 2], [3, 4]])
    ... except Exception:
    ...     print("error")
    error

M_b is a string:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], "string")
    ... except Exception:
    ...     print("error")
    error

M_a is empty:

    >>> try:
    ...     lazy_matrix_mul([], [[1, 2], [3, 4]])
    ... except Exception:
    ...     print("error")
    error

M_b is empty:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [])
    ... except Exception:
    ...     print("error")
    error

M_a contains a non-number:

    >>> try:
    ...     lazy_matrix_mul([[1, "2"], [3, 4]], [[1, 2], [3, 4]])

    >>> try:
