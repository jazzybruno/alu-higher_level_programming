===============================

Normal division, rounded to 2 decimals, without changing the matrix:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

    >>> matrix_divided([[1.5, -2.5], [3, 4]], 0.5)

    >>> matrix_divided([[2, 4]], -2)

Dividing by infinity:
