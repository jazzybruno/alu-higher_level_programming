# Python - import & modules

Importing functions and variables from other files, creating modules, inspecting them with `dir()`, guarding code with `if __name__ == "__main__":`, and reading command line arguments.

| File | Description |
|------|-------------|
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `1-calculation.py` | Imports the functions from `calculator_1.py` and prints their results |
| `2-args.py` | Prints the number of arguments and each argument |
| `3-infinite_add.py` | Prints the sum of all arguments |
| `4-hidden_discovery.py` | Prints the names defined in `hidden_4.pyc` |
| `5-variable_load.py` | Imports and prints the variable `a` from `variable_load_5.py` |
| `100-my_calculator.py` | Command line calculator using `calculator_1.py` |
| `101-easy_print.py` | Prints `#pythoniscool` without `print` |
| `102-magic_calculation.py` | `magic_calculation(a, b)`: Python equivalent of the given bytecode |
| `103-fast_alphabet.py` | Prints the uppercase alphabet without loops or string literals |
