# SQL - Introduction

First steps with MySQL 8.0: creating and dropping databases and tables, inserting, selecting, updating and deleting rows, and aggregate functions.

| File | Description |
|------|-------------|
| `0-list_databases.sql` | Lists all databases |
| `1-create_database_if_missing.sql` | Creates `hbtn_0c_0` if it is missing |
| `2-remove_database.sql` | Drops `hbtn_0c_0` if it exists |
| `3-list_tables.sql` | Lists the tables of a database |
| `4-first_table.sql` | Creates `first_table` |
| `5-full_table.sql` | Shows the full description of `first_table` without `DESCRIBE` |
| `6-list_values.sql` | Lists all rows of `first_table` |
| `7-insert_value.sql` | Inserts `(89, 'Best School')` |
| `8-count_89.sql` | Counts records with `id = 89` |
| `9-full_creation.sql` | Creates `second_table` and inserts four rows |
| `10-top_score.sql` | Lists score and name by score descending |
| `11-best_score.sql` | Lists records with a score of at least 10 |
| `12-no_cheating.sql` | Sets Bob's score to 10 using his name |
| `13-change_class.sql` | Deletes records with a score of 5 or less |
| `14-average.sql` | Average score as `average` |
| `15-groups.sql` | Number of records per score, labelled `number` |
| `16-no_link.sql` | Lists named records by score descending |
