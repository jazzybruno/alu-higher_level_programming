# Python - Classes and Objects

Introduction to object-oriented programming in Python: classes, instances, private attributes, properties with validating setters, and methods.

| File | Description |
|------|-------------|
| `0-square.py` | Empty class `Square` |
| `1-square.py` | `Square` with a private `size` set at instantiation |
| `2-square.py` | `Square` whose `size` must be an integer >= 0 |
| `3-square.py` | Adds the public `area()` method |
| `4-square.py` | Adds a `size` property with a validating setter |
| `5-square.py` | Adds `my_print()`, which prints the square with `#` |
| `6-square.py` | Adds a validated `position` property used to offset `my_print()` |
| `100-singly_linked_list.py` | `Node` and `SinglyLinkedList` with `sorted_insert()` keeping values in increasing order |
| `101-square.py` | `Square` whose `print()` output matches `my_print()` |
| `102-square.py` | `Square` with a numeric size, compared by area with `==`, `!=`, `<`, `<=`, `>`, `>=` |
| `103-magic_class.py` | `MagicClass` (a circle) rebuilt from Python bytecode |
