# Python - More Classes and Objects

A `Rectangle` class built up step by step: validated properties, `__str__` and `__repr__`, `__del__`, class attributes, a static method and a class method.

| File | Description |
|------|-------------|
| `0-rectangle.py` | Empty class `Rectangle` |
| `1-rectangle.py` | Validated `width` and `height` properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | `str()` draws the rectangle with `#` |
| `4-rectangle.py` | `repr()` returns a string that `eval()` can turn back into a rectangle |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Class attribute `number_of_instances` counts live instances |
| `7-rectangle.py` | Class attribute `print_symbol` sets the drawing symbol |
| `8-rectangle.py` | Static method `bigger_or_equal()` returns the rectangle with the bigger area |
| `9-rectangle.py` | Class method `square()` builds a rectangle with equal sides |
