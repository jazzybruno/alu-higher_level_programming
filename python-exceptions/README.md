# Python - Exceptions

Handling errors in Python 3 with `try`, `except`, `else` and `finally`, and raising built-in exceptions.

| File | Description |
|------|-------------|
| `0-safe_print_list.py` | `safe_print_list(my_list, x)`: prints up to `x` elements and returns how many were printed |
| `1-safe_print_integer.py` | `safe_print_integer(value)`: prints a value only if it is an integer |
| `2-safe_print_list_integers.py` | `safe_print_list_integers(my_list, x)`: prints the integers among the first `x` elements |
| `3-safe_print_division.py` | `safe_print_division(a, b)`: divides two integers and prints the result in `finally` |
| `4-list_division.py` | `list_division(my_list_1, my_list_2, list_length)`: divides two lists element by element |
| `5-raise_exception.py` | `raise_exception()`: raises a `TypeError` |
| `6-raise_exception_msg.py` | `raise_exception_msg(message)`: raises a `NameError` with a message |
| `100-safe_print_integer_err.py` | `safe_print_integer_err(value)`: prints an integer, or the error on stderr |
| `101-safe_function.py` | `safe_function(fct, *args)`: runs a function and reports any exception on stderr |
| `102-magic_calculation.py` | `magic_calculation(a, b)`: Python equivalent of the given bytecode |
