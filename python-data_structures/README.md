# Python - Data Structures: Lists, Tuples

Working with lists and tuples in Python 3: indexing, slicing, common list methods, list comprehensions, tuple packing and sequence unpacking, and `del`.

| File | Description |
|------|-------------|
| `0-print_list_integer.py` | `print_list_integer(my_list)`: prints every integer of a list |
| `1-element_at.py` | `element_at(my_list, idx)`: returns an element, or `None` when out of range |
| `2-replace_in_list.py` | `replace_in_list(my_list, idx, element)`: replaces an element in place |
| `3-print_reversed_list_integer.py` | `print_reversed_list_integer(my_list)`: prints the integers in reverse |
| `4-new_in_list.py` | `new_in_list(my_list, idx, element)`: replaces an element in a copy |
| `5-no_c.py` | `no_c(my_string)`: removes every `c` and `C` |
| `6-print_matrix_integer.py` | `print_matrix_integer(matrix)`: prints a matrix of integers |
| `7-add_tuple.py` | `add_tuple(tuple_a, tuple_b)`: adds the first two elements of two tuples |
| `8-multiple_returns.py` | `multiple_returns(sentence)`: returns the length and first character |
| `9-max_integer.py` | `max_integer(my_list)`: returns the biggest integer |
| `10-divisible_by_2.py` | `divisible_by_2(my_list)`: flags the multiples of 2 |
| `11-delete_at.py` | `delete_at(my_list, idx)`: deletes the item at an index |
| `12-switch.py` | Swaps the values of `a` and `b` |
