# Python - Network #0

HTTP basics with cURL: request methods, headers, body size, redirects and form parameters.

| File | Description |
|------|-------------|
| `0-body_size.sh` | Size of the response body in bytes |
| `1-body.sh` | Body of a 200 response, following redirects |
| `2-delete.sh` | Sends a `DELETE` request |
| `3-methods.sh` | Lists the methods the server allows for a URL |
| `4-header.sh` | Sends `X-HolbertonSchool-User-Id: 98` |
| `5-post_params.sh` | Sends a `POST` with `email` and `subject` |
