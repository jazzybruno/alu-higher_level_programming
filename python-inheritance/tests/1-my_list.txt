The ``1-my_list`` module
========================

Using ``MyList``
----------------

    >>> MyList = __import__('1-my_list').MyList

MyList is a list:

    >>> issubclass(MyList, list)
    True

Printing an unsorted list sorts the output only:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Negative numbers and duplicates:

    >>> my_list = MyList([3, -1, 3, 0, -7])
    >>> my_list.print_sorted()
    [-7, -1, 0, 3, 3]

An empty list:

    >>> MyList().print_sorted()
    []

A list with one element:

    >>> MyList([42]).print_sorted()
    [42]

A list that is already sorted:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]

print_sorted returns nothing:

    >>> MyList([2, 1]).print_sorted() is None
    [1, 2]
    True
